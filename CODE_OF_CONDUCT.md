# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be respectful and constructive in issues, pull requests and
discussions; assume good intent; no harassment, personal attacks or
discrimination of any kind.

Maintainers may edit, remove or lock contributions that break these rules and
may block repeat offenders from the organisation's repositories.

To report a problem, contact the maintainers through the
[repository's security advisory form](https://github.com/qodalis-solutions/web-cli/security/advisories/new)
(it is private) or by mentioning a maintainer in the thread. Reports are handled
confidentially.
