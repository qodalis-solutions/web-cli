    Represents command processor metadata

    Type Declaration

    • Optionalhidden?: boolean

      If true, the processor is hidden from the help command listing. The command still works when typed directly and help <command> still shows its details.

    • Optionalicon?: CliIcon | string

      An icon to display for the processor

    • OptionalliteralInput?: boolean

      The command's text is code or other literal input (eval): the engine passes the whole line as typed, without operators (|, ;, &&, >) or expansion of $(...), $VAR, braces and wildcards, so eval [1,2].map(x => x * 2) keeps its =>, * and ${...}.

    • Optionalmodule?: string

      The module the processor belongs to

    • OptionalrequireAuth?: boolean

      If true, the command requires a signed-in user. Enforced by a core guard that activates when an auth module registers an ICliAuthorizationService (e.g. @qodalis/cli-users); without one the flag is informational.

    • OptionalrequiredCliVersion?: string

      The minimum required version of @qodalis/cli for this processor. If the installed CLI version is lower, the processor will be skipped during boot.

    • OptionalrequiredCoreVersion?: string

      The minimum required version of @qodalis/cli-core for this processor. If the installed core version is lower, the processor will be skipped during boot.

    • OptionalrequiredGroups?: string[]

      The signed-in user must belong to at least one of these groups (e.g. ['admin']). Implies requireAuth. Enforced like requireAuth.

    • OptionalrequiredPermissions?: string[]

      The signed-in user must hold all of these permissions (e.g. ['users:create']), granted through their groups (roles). Implies requireAuth. Enforced like requireAuth.

    • OptionalrequireServer?: boolean

      If true, the processor requires the server to be running

    • Optionalsealed?: boolean

      If true, the processor is sealed and cannot be replaced or removed. Sealed processors can still be extended (wrapped) by processors with extendsProcessor = true.
