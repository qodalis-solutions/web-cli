    Interface ICliEventBus

    Publish/subscribe bus shared by the system, modules and commands of one terminal. Handlers run synchronously in subscription order; a failing handler is logged and does not affect the others or the emitter.

    Patterns: an exact type (package:installed), a namespace wildcard (package:*) or * for everything.

    Events live in memory: each terminal has its own bus for its lifetime, with a short recent history, and nothing is persisted.

    Get it from a command or module with context.events, or from the services container with ICliEventBus_TOKEN.

    on

    • on<K extends keyof CliEventMap>(
          pattern: K,
          handler: CliEventHandler<CliEventMap[K]>,
      ): () => void

      Handle events matching pattern. Returns a function that unsubscribes.

      bus.on('package:installed', (e) => e.data.version); // typed from CliEventMap
      bus.on<TodoAdded>('todo:added', (e) => e.data.text); // explicit payload type
      bus.on('server:*', (e) => console.log(e.type));      // anonymous: data is unknown
