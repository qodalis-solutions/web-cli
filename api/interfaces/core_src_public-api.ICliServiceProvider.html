    • remove?(service: any, provider?: unknown): boolean

      Remove a registration. With provider (the provider object passed to set, or the registered value), only that registration is removed: for a single token the previous registration becomes active again, for a multi token the others remain. Without it, every registration of the token is removed. Sealed tokens cannot be removed.
