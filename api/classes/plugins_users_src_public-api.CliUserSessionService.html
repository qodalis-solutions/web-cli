    Class CliUserSessionService

    Current sign-in session for this CLI, on top of an ICliUsersBackend. Holds the session token (persisted in the KV store) and the session (user + effective permissions). Same implementation in both modes.

    su nests sessions like Unix shells: push suspends the current session (its token stays valid on the backend) and pop resumes it.
