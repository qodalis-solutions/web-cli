    Class CliServiceContainer

    A simple Map-based service container implementing ICliServiceProvider.

    Supports three provider types:

    • useValue : registers a static value
    • useFactory : registers a factory function, invoked once on the first get
    • useClass : registers a class constructor, instantiated once on the first get

    Factories and classes are created lazily, so their deps only have to be registered by the time the service is first used. Add transient: true to create a new instance on every get.

    When multi: true, multiple providers for the same token are accumulated and getAll() returns all of them.

    Registering a single token again overrides it; removing that registration (remove(token, provider), e.g. when a module is unloaded) makes the previous one active again.

    • dispose(): void

      Dispose the services the container created (useFactory / useClass) that have a dispose() method. Values registered with useValue belong to whoever registered them and are not disposed. Registrations are kept, so late callbacks still find their services. Called when the engine is destroyed; later calls do nothing.
