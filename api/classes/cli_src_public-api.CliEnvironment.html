    Class CliEnvironment

    Default in-memory implementation.

    A variable resolves, in order, from this terminal's variables (NAME=value), the current user's own (export), the shared ones (export --global), then bound live values (USER, HOME, PWD follow the session and directory), then the standard variables seeded on construction. Each user has a separate set, so su/login switch environments, and onChange lets the host save each change.
