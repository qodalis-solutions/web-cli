    Class CliPanelController

    Framework-agnostic state and behaviour of the collapsible CLI panel: tabs and panes, chrome (collapse, hide, maximize, position, size), menus, drag resizing, theme sync and the status bar.

    Views subscribe with subscribe and render getSnapshot; every change produces a new immutable snapshot. Hosts may control any of the bindable values through setControlled; the matching onXChange callback is invoked whenever the panel wants to change it.
