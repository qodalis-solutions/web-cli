    Class CliPanelController

    Framework-agnostic state and behaviour of the collapsible CLI panel: tabs and panes, chrome (collapse, hide, maximize, position, size), menus, drag resizing, theme sync and the status bar.

    Views subscribe with subscribe and render getSnapshot; every change produces a new immutable snapshot. Hosts may control any of the bindable values through setControlled; the matching onXChange callback is invoked whenever the panel wants to change it.

    pickTheme

    • pickTheme(theme: string, colors?: Partial<CliPanelCustomColors>): void

      The user picks a theme in the theme picker: 'auto', 'light', 'dark', a terminal theme's name, or 'custom' for their own colors (the saved ones, or the current look to start from; colors replaces any of them). The panel and every terminal in it change, a theme applied with the theme command gives way to it, the pick is remembered for the next visit and the host is told (onThemeChange). The picker stays open on Custom, for its color pickers.
