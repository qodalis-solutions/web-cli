Class CliHttpError

Error thrown by ICliHttpClient JSON helpers (get, post, put, patch, delete, options) when the server responds with a non-2xx status.

Exposes the HTTP status so callers can react to specific responses (for example, clearing a stored session token on 401).

Example

try {
    await context.http.get(url);
} catch (e) {
    if (e instanceof CliHttpError && e.status === 401) {
        // token expired or revoked
    }
}
