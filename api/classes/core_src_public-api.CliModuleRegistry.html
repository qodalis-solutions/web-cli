    Class CliModuleRegistry

    Registry that tracks loaded web CLI modules (frontend plugins) and dispatches boot handlers when new modules are registered (including dynamically via UMD).

    This registry is for browser-side web plugins only. Backend server processors (Node/Python/.NET) have their own registries and do not use this class or the apiVersion gating mechanism.
