    update

    • update(change: (state: CliState) => Partial<CliState>): Promise<void>

      Change the state from its latest saved value and save it, atomically: under the cross-tab lock, change gets the state as saved (plus this terminal's unsaved changes) and its result is merged and written. Two terminals updating the same key never lose each other's change, e.g. both adding an item to a list. Without storage (or for a session store) it is a plain updateState.

      Parameters

      • change: (state: CliState) => Partial<CliState>

      Returns Promise<void>
