    Class CliBootLog

    Live boot report written to the terminal while the CLI starts: a list of the steps (terminal, services, servers, modules) with a thin progress bar and percentage pinned below it.

    Anything else written to the terminal meanwhile is captured and the bar steps aside for it. When boot is complete the report is cleared so the regular terminal takes over; warnings, errors and other output (plugin warnings) are written again in order. First-run setup prompts, answered while the report is suspended, are cleared with it.

    A disabled log records problems but writes nothing.
