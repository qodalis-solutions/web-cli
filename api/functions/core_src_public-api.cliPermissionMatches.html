Function cliPermissionMatches

  • cliPermissionMatches(granted: string, required: string): boolean

    Permission strings are resource:action (for example users:create). A trailing * segment matches anything at that level and below; a * in any other position matches exactly one segment:

    granted matches
    * every permission
    users:* users:create, users:delete, ...
    *:read users:read, groups:read, ...
    users:read only users:read

    Matching is case-insensitive.

    Parameters

    • granted: string
    • required: string

    Returns boolean
