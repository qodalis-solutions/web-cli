What it is

The app is the Qodalis CLI terminal packaged for phones: the same engine and plugins as this site, in a full-screen terminal with keys made for touch screens. It needs Android 7.0 or later, has no online account and needs no server. The same app runs in the browser as a PWA at qodalis-solutions.github.io/pwa-cli. Its source is qodalis-solutions/pwa-cli.

What runs on the device

Everything below works offline, without a server. Files, settings and installed packages are kept on the phone.

AreaCommands
Developer toolsguid, hash, base64, jwt, regex, json, string tools, password generator
Filesls, cd, cat, grep, sed, awk, find, tree, pipes, aliases and the nano editor
Networkcurl, wget, speed-test: the only commands that go online, and only to the URLs you give
ProductivityTo-do list, stopwatch, QR codes, Markdown, charts
UsersThe first launch creates your account on the phone; whoami, adduser, su, passwd, login / logout
Phonedevice, battery, network, share, vibrate, toast
Games2048, Tetris, Snake, Minesweeper, Sudoku, Wordle, played by touch or keyboard
  • More plugins: pkg browse lists the published plugins, pkg add <name> installs one (for example pkg add csv) and keeps it across launches, pkg remove <name> drops it.
  • Themes: theme list lists them, theme apply dracula switches.
  • Languages: English and 10 translations. The app starts in the phone's language when one matches; configure set system.language de changes it.
  • Your own server: server add links a Node, .NET or Python server, so its commands run from the phone. See {{ 'sidebar.connect-your-server' | translate }}.

Made for phones

FeatureDetails
Extra keysTwo rows above the keyboard: Esc, Tab, Ctrl, Ctrl+C, Home, End, Del, the arrows and / | -, sent as real key presses. Ctrl is sticky: tap it, then a key (Ctrl+A, E, U, K, W, L); double-tap locks it. Held arrows and Del repeat
Command keysFull-screen commands show their own keys instead: nano gets Save, Exit, Find, Cut, Paste and PgUp/PgDn; games get big buttons and swipes, and the on-screen keyboard closes
KeyboardOn Android the keyboard sends plain key presses (Capacitor's captureInput), so there are no suggestions or autocorrect: commands arrive exactly as typed, and the keyboard does not learn what you type, passwords included. The terminal stays above the keyboard
Back buttonCloses the keyboard; in a game or a prompt it presses Escape; otherwise (or pressed twice) it sends the app to the background and keeps the session
Edge to edgeThe terminal fills the screen around notches and the navigation bar; the system bars follow the terminal's colors
IntroductionThe first launch shows a few slides of what the app does; intro shows them again

Privacy

Accounts, files and history stay on the phone. The Android app sends anonymous usage statistics (analytics off stops them) and shows ads. The policy is at cli.qodalis.com/privacy, and the privacy command shows it in the app.

iPhone, iPad and desktop

Apps for iOS and desktop are planned. Until then, install the PWA: it is the same terminal, works offline once loaded and keeps its files in the browser.

  • iPhone and iPad: open the PWA in Safari, tap Share, then Add to Home Screen.
  • Desktop (Chrome, Edge): open the PWA and click the install icon in the address bar, or Install in the browser menu.
  • Android without Google Play: open the PWA in Chrome and choose Add to Home screen / Install app.
