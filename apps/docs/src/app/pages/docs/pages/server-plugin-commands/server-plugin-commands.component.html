Every server plugin can be driven from the terminal. A command comes from one of two places:

  • Server: a command processor of the server plugin, the same on the Node, .NET and Python servers. The web CLI lists it once connected to the server (server add) and runs it there. On a protected server it needs commands:execute plus the permission shown, checked along the command chain (the root command's permission covers its sub-commands).
  • A web-cli package (@qodalis/cli-server-jobs, @qodalis/cli-users, ...): a client command that calls the plugin's REST API. Add the package's module to the terminal (or pkg add it); the server checks the permission shown on each request.

"Permission" is what a protected server checks (users plugin); an open server allows everything. Empty means nothing beyond commands:execute. Run help <command> in the terminal for every flag. For the server's REST API and MCP tools, see Server Integration.
