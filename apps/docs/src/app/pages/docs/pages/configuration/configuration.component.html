When omitted it is looked up next to the page (document.baseURI), then at /assets/wasm/ and /wasm/. Set it when the app is served under a sub-path. The CLI falls back to JavaScript when the file is missing.

Server Configuration

Each entry in the servers array uses the CliServerConfig type:

Option Type Default Description
name string (required) Unique identifier. Server commands are prefixed with this name.
url string (required) Base URL, e.g. "http://localhost:8047"
enabled boolean true Set to false to skip this server on startup
headers Record<string, string> | () => Record<string, string> {} Static or dynamic headers. Use a function for rotating tokens (e.g. JWTs).
timeout number 30000 Request timeout in milliseconds 
servers: [
    { name: 'node', url: 'http://localhost:8047' },
    {
        name: 'api',
        url: 'https://api.example.com',
        headers: () => ({ Authorization: 'Bearer ' + getToken() }),
        timeout: 10000,
    },
]

Panel Configuration

When using the <cli-panel> component, pass panel-specific options via the options prop. The CliPanelOptions type extends CliOptions with CliPanelConfig properties:

Option Type Default Description
isCollapsed boolean true Whether the panel starts collapsed
isHidden boolean false Whether the panel starts hidden (showing only the small tab)
position 'bottom' | 'top' | 'left' | 'right' 'bottom' Panel position relative to the viewport
closable boolean true Whether the close button is shown
resizable boolean true Whether the panel can be resized by dragging
hideable boolean true Whether the hide button is shown
hideAlignment 'start' | 'center' | 'end' 'center' Alignment of the hidden-mode tab along the viewport edge
syncTheme boolean false Auto-sync panel chrome colors with the active terminal theme 
const panelOptions: CliPanelOptions = {
    position: 'right',
    isCollapsed: false,
    isHidden: false,
    closable: true,
    resizable: true,
    syncTheme: true,
    hideAlignment: 'end',
};

import '@qodalis/cli/assets/styles.css';
import { CliEngine } from '@qodalis/cli';
import type { CliOptions } from '@qodalis/cli-core';

const options: CliOptions = {
    logLevel: 'DEBUG',
    welcomeMessage: 'Welcome to my app!',
    theme: 'default',
    servers: [
        { name: 'dotnet', url: 'http://localhost:8046' },
    ],
};

const container = document.getElementById('terminal')!;
const engine = new CliEngine(container, options);

engine.start().then(() => engine.focus());
}
