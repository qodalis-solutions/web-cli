{{ 'docs.ai-plugin-development.prompts-desc' | translate }}

Web plugin 
Create a Qodalis CLI web plugin "weather" with sub-commands "current" and "forecast"
that call https://wttr.in, a --units parameter (metric|imperial), a spinner while loading
and CliTestHarness tests. Scaffold it with create-cli-plugin.
Server command 
Add a "disk-usage" command to my Node CLI server that returns a table of mounted
volumes (structured output), requires the permission "system:read", and add a Vitest test.
Interactive command 
Write a web command "deploy" that asks for the environment with readSelect, confirms
with readConfirm, handles Ctrl+C (null answers) and posts to /api/deploy with context.http.
With a server 
List the commands of my CLI server and run "weather current --location Paris".
